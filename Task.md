# Notes App Backedn in FastApi
Will create a notes app in fastapi.

## Endpoints
- /create: <br>
To create a new note

- /getnotes: <br>
To get all the saved notes

- /get/{id}: <br>
To get a particular note with id

- /update/{id}: <br>
To update a note with given id

- /delete/{id}: <br>
To delete a particular note
